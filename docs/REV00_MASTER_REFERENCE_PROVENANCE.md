## reflector_generation_inputs

### `dec_GAD_reflector_strip.inp`

Generated DeCART2D input used to calculate the representative reflector HGC files.

It uses a reduced strip geometry rather than the full 9x9 MASTER map, so that the relevant fuel-reflector boundaries can be generated at reasonable cost. The strip uses:

```text
O R3 R2 FA_A2 FA_B2 FA_A2 R2 R3 O
R1 FA_A2 FA_B2 FA_B1 FA_B1 FA_B1 FA_B2 FA_A2 R1
O R3 R2 FA_A2 FA_B2 FA_A2 R2 R3 O
```

### `pro_GAD_reflector_strip.inp`

PROMARX input used to read the generated DeCART/HGC files and produce the PROMARX reflector XS file.

### `HYUSENM_Input.inp`

Input for the HYUSENM reflector postprocessor. It maps representative HGC pairs to reflector types:

```text
R1: GAD_reflector_strip_0805.HGC | GAD_reflector_strip_0905.HGC
R2: GAD_reflector_strip_0604.HGC | GAD_reflector_strip_0704.HGC
R3: GAD_reflector_strip_0704.HGC | GAD_reflector_strip_0804.HGC
```

## reflector_hgc

Contains the 27 DeCART2D HGC files generated by `dec_GAD_reflector_strip.inp`.

These are not the original standalone fuel-assembly HGC files. They are reflector-generation HGC files from the reduced strip model and include reference plus `DMOD1` through `DMOD6` branch data.

## reflector_xs_promarx

### `pro_GAD_reflector_strip.xsd`

PROMARX reflector cross-section output generated from the strip HGC files.

### `pro_GAD_reflector_strip.out`

PROMARX text output/log. It records that the PROMARX job finished successfully.

## reflector_xs_hyusenm

### `RADIAL_XSL.h5`

HYUSENM-ready radial reflector cross-section library generated from the strip HGC files.

The HDF5 file contains top-level reflector groups:

```text
R1
R2
R3
```

Each group contains:

```text
REF
DMOD
METADATA
```

### `Reflector.out`

Human-readable HYUSENM postprocessor output. It lists discontinuity factors and effective reflector cross sections for `R1`, `R2`, and `R3`.

## Important Assumptions

Only two DeCART fuel-assembly inputs were provided for a MASTER model that names six fuel components. The generated reflector model therefore used this mapping:

```text
FA_A0, FA_A1, FA_A2, FA_A3 -> 10_16_z1
FA_B1, FA_B2              -> 10_20_z1
R1, R2, R3                -> MASTER reflector labels
```

For the final MASTER trial run, the six required fuel HGC filenames were created from the two provided GAD HGC files according to the mapping above. The new GAD reflector XS replaced only the radial reflector part of `MAS_REF`; the axial reflector blocks were retained from the existing MASTER `MAS_REF` template.

The assembly definitions include Gd/IGD pins through:

```text
mixture UO2G ... / 92235 4.0 6408 10.0
cell 3 2 / UO2G AIR CLADF COO
```

## Recommended Files for Use

For PROMARX-style reflector XS use:

```text
reflector_xs_promarx\pro_GAD_reflector_strip.xsd
```

For HYUSENM-style reflector XS use:

```text
reflector_xs_hyusenm\RADIAL_XSL.h5
```

For traceability, keep the corresponding files in `assembly_hgc`, `master_input`, `reflector_generation_inputs`, and `reflector_hgc` together with these outputs.
