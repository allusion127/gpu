# A=149 Pm/Sm 체인 계약 테스트 — 스파이크 가설 상태

`tools/test_sm149_chain_contract.py`가 고정한 것: `dep_trans.csv`의 611490(Pm-149) 행이
U-235/U-238/Pu-239 핵분열 수율(1.0820E-02 / 1.6250E-02 / 1.2160E-02)을 갖고 601490(Nd-149)
행은 갖지 않는다는 것, `dep_decay.csv`의 621490(Sm-149)←611490 생성항이
λ(Pm-149)=3.627372e-06 s⁻¹, 601490(Nd-149) 대각이 -λ(Nd-149)=-1.114241e-04 s⁻¹라는 것,
그리고 `ComputeXeEquilibrium`이 I-135/Xe-135/Xe-135m 세 행만 쓰고 `IO.cpp`에 "samarium"
덱 키가 없다는 것(RASBERY의 Sm-149는 무조건 transient — MASTER SM mode 2와 동형, MASTER-3.0
매뉴얼 p.3-46).

## 스파이크 가설 상태

`docs/CAMPAIGN_STATUS_20260904_KO.md` §5: i-SMR 3주기 공통으로 **1.96 d 첫 감손 스텝**에서
+205~266 pcm 스파이크가 나타나고 19.6 d에 소멸한다. MASTER는 `XE/SM='1 2'`(Sm transient)를
쓰고 RASBERY도 Sm 모드가 없어 둘 다 transient이므로, 스파이크는 SM 모드 차이가 아니라
**A=149 체인의 타이밍**(Nd-149를 거치지 않고 핵분열 수율을 Pm-149에 직접 배정하는 관례,
Pm-149의 T½=53h 첫 스텝 CRAM 적분과 MASTER의 처리 사이의 미세한 차이) 후보로 남는다.

이 테스트의 순수-python Bateman 폐형식(§(c))은 λ(Pm-149)·t=1.963d에서 buildup fraction이
**~0.2531**임을 확인한다 — 절반이 붕괴했으리라는 반감기 기반의 직관적 추정(~0.50, 반감기
2.21d와 1.963d가 우연히 비슷해서 나온 어림)과는 다른 실제 폐형식 값이다. 이 차이 자체가
교훈: 두 숫자가 가깝다고 관련이 있는 것은 아니다.

**미해결 — 진폭.** 이 2-동위원소 폐형식은 *타이밍*만 고정할 뿐 실제 keff 스파이크의 *진폭*
(+205~266 pcm)은 설명하지 못한다 — 그것은 3-D 결합 물리(플럭스 피드백, 노드별 CRAM,
TH 결합)의 산물이라 순수 두 동위원소 ODE로 환원되지 않는다.

**판별 실험.** `docs/CAMPAIGN_STATUS_20260904_KO.md` §6.3에 기록된 **181 3-D Xe/Sm 첫 스텝
세분화 실험(54e)**이 진폭 가설의 실제 판별자다: 1.963 d 스텝을 여러 서브스텝으로 쪼갰을 때
스파이크가 줄어들면 시간이산화 아티팩트, 줄지 않으면 A=149 체인 자체의 물리적 특성.

## 갱신 (2026-09-05): 스파이크 원인 확정

- 181 MASTER HIGA 3-D Xe/Sm 에디트 런과 RASBERY 핵종 밀도(Pm-149/Sm-149/I-135/Xe-135, 1.870 d·18.696 d)가 0.0~0.7 % 일치 → A=149 체인 가설은 **기각**. 이 문서의 체인 계약 테스트는 회귀 방지용으로 유지한다.
- 실제 원인: RASBERY i-SMR CHIFFON 라이브러리의 연소도 격자 첫 비영점이 0.2 GWd/t(0, 0.2, 0.5, 1, …)라 0.05 GWd/t(1.963 EFPD)에서 FP-free bu=0 micro-σ가 25 % 가중으로 선형보간됨(src/XSSet.cpp 1856-1963). 무한매질 재구성 Δρ ≈ +303 pcm(lumped FP 기여 ≈ 3 pcm). MASTER의 PROLOG 격자는 0.1 GWd/t 간격이라 무릎을 해상함.
- 수정: dec_FA_*.inp DEPL 카드에 0.05/0.1/0.3/0.75 GWd/t 추가 후 DeCART2D 재실행·라이브러리 재생성(N1, i-SMR 한정). 상세는 docs/ISMR_XS_BURNUP_GRID_20260905_KO.md(작성 예정).
